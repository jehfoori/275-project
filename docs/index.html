Artificial Life City Simulation

A 3D predator–prey artificial-life demo built in Unity. Crowd agents use Boids-style flocking, waypoint navigation, and stress-driven evacuation while predators pursue prey through a bounded city.

Behavior Model

Perception

Agents sense nearby flockmates, predators, obstacles, and map boundaries using spatial queries.

Flocking

Separation, alignment, and cohesion produce emergent crowd movement when agents are calm.

Threat response

Predator detection triggers fleeing, panic contagion, and evacuation routing toward exit points.

Predators

Simple pursuit steering with obstacle avoidance; predators consume nearby prey on contact.

Architecture

  • PreyAgent — perception, stress/fatigue, flocking, flee, path follow
  • PredatorAgent — pursuit, wander, eat, health
  • SimulationManager — spawning, spatial index, evacuation flow field, HUD
  • CityNavigation — waypoint graph built from scene markers and building colliders
  • WebGlRuntimeBootstrap — lighter agent counts when running in the browser

Run Locally (Unity)

  • Open Assets/Scenes/MainSimulation.unity
  • Press Play — civilians and soldiers spawn automatically
  • Click Spawn Predator to add predators
